# Fuentes de kilometraje

`Kilometros.xlsx` es el archivo de referencia recibido para los odómetros y méritos personales de Chilangos RC.

La versión almacenada aquí incluye la corrección de Inra: Iron 883 y Road King sin lectura registrada, y Ultra Clasic de 35,635 a 40,635 kilómetros (5,000 km acumulados y mérito de 5K alcanzado).
