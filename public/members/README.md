# Fotografías de integrantes y motocicletas

Cada retrato debe estar autorizado por la persona correspondiente:

```text
public/members/ronnie/retrato.jpg
public/members/ronnie/motos/roadster.jpg
public/members/austria/retrato.jpg
public/members/austria/motos/road-glide.jpg
```

Después actualiza `portrait`, `motorcycles` y los datos autorizados dentro de
`app/data/biker-profiles.ts`.

No publiques placas, domicilios, teléfonos, apellidos, fechas de nacimiento,
ubicaciones privadas ni información familiar que no esté autorizada.
